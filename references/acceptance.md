# 逐图验收

在检查前写下稿件宽度、字体环境、已知替代项和预期对象数。保存参考图、实际 PDF 导出和每次修正后的证据。单页记录可采用“图号｜稿件宽度｜核对的文字／公式和边｜自动检查结果｜目检发现与修正｜尚待确认项”。有遗留问题的页标为待复核。

| 检查对象 | 检查方法 | 可交付的结果 |
|---|---|---|
| 内容与拓扑 | 按原件逐字读标签和公式，逐边沿起点、分叉、交叉和箭头走到终点。在并排校样上核对方向、相邻关系与图例 | 每个模块、公式和连接均有对应；可分辨反馈与前向、条件与输出。所有经同意的差异均可定位 |
| 排版与字体 | 在实际栏宽查看，再局部放大端口、拐点、文字及基线。核对组内外间距、框内文字墨迹中心、跨面板对齐、裁边及叠放顺序 | 标签清晰，字号可读；框、线、公式互不意外遮挡，箭头贴合目标，弧线连续。字体替换已记录 |
| 公式与比例 | 每项检查符号身份、上下标层次、括号范围和运算符。打开 PPTX 的公式编辑器，配合原生结构计数、公式校准与最终 PDF 字形测量 | 可修改公式内部符号。字形正常，未因单独拖拽宽或高而变形；所有异常项已定位并重新导出 |
| 对象与矢量 | 检查形状选择窗格、可编辑文本和 OMML。运行结构审计，检查重复对象 ID、隐藏标志、图片、实际 PDF 图像绘制、字体嵌入和异常字符 | 声明为全矢量的页无位图，可见正文可选取，插画可拆组改色。底板、截图和隐藏替身不能通过验收 |
| 修改后的可见效果 | 在副本内改标签、修改公式的一个元素、移动一个组件；对同一环境前后的 PDF 逐页比较。检查改动后文字和下标的实际值、位移方向与距离 | 指定小区域分别有可见变化，未授权区域与其他页无变化。无公式的页验证适用的对象类型 |
| 论文输出 | 从本次 PPTX 导出，重新打开每个裁切后的单页 PDF；用稿件模板或目标物理尺寸确认四边和细部。需要特定 Office 版本时，在指定版本复核 | 每个单页对应正确图号，尺寸和裁边适配，字体嵌入、内容完整、矢量保留；对照校样单独交付 |

**工具判定的边界。** 报告中的 OMML 数量无法验证方程语义。可提取的 PDF 文字也无法单独证明视觉上的每个标签都可编辑。结构审计会提示包内残留的位图资源，包括未引用资源；定位并清除或说明。像素比较用于同一渲染器下的局部编辑检验，跨字体或渲染器时先统一环境。输入图与重绘图允许手工复刻级别的小差异，视觉验收应使用原件、排版和科学含义共同判断。

**返修。** 把发现具体到页号、对象与导出位置，例如“图 2，条件支路右转箭头末段跨过目标端口”。修正绘图定义、重建受影响的页，重新检查最终导出并更新记录。每页完成以上适用项后，再汇总整套结果。
